იდოკის MCP — კოდი (ამ საქაღალდეს კითხულობს გაფართოება „იდოკი (eDocument)“). დეტალები — DEVELOPMENT.md.
core/edoc.js — იდოკის კლიენტი (შესვლა, დავალებები, ვიზირება, ხელმოწერა, უსაფრთხოების წესები).
core/vpn.js  — VPN: უნივერსიტეტის ქსელის/VPN-ის შემოწმება, FortiClient-ის ჩართვა (გზა თითო კომპიუტერზე ინახება %LOCALAPPDATA%\edoc-mcp\vpn-state.json).
core/ignore.js — ignore-list: ვიზის/ხელმოწერის ჩანაწერები, რომლებიც აღარ უნდა ჩანდეს მოლოდინში (ფაილი: Drive-ზე .data\ignore.json).
tools.js     — MCP ადაპტერი (Claude და სხვა AI კლიენტები).
cli.js       — ბრძანების ხაზი: node cli.js tasks | vises --pending | vise <ნომერი> --confirm ...
vpn.js       — ძველი მისამართის შიმი, შეიძლება წაიშალოს.
.tests/      — ტესტები ყალბ იდოკზე: node .tests/test.mjs
